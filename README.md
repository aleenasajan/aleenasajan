## 🚀 Featured Research

### A Local LLM-Based Geospatial Assistant Using MCP and RAG for Natural Language Spatial Queries

*Lab Rotation 2 – Karlsruhe Institute of Technology (KIT)*

Exploring the integration of a locally deployed Large Language Model (Gemma 4 via Ollama), Model Context Protocol (MCP), and Retrieval-Augmented Generation (RAG) to enable natural-language interaction with QGIS.

**Key components:**
- Local LLM inference using Gemma 4 and Ollama.
- MCP-based integration between the LLM and QGIS tools.
- RAG-based retrieval of GIS and project-specific knowledge.
- Natural-language spatial queries and GIS tool execution.
- Experimental evaluation of integrated query workflows.
